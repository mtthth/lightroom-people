# Lightroom People

Plugin Lightroom Classic (projet) pour exploiter les mots-clés « personne » :

- collections (fixes et dynamiques) par personne et par âge ;
- fenêtre « Parcourir par âge » ;
- gestion des personnes décédées et des photos numérisées ;
- génération d'albums selon un rythme (1/heure le premier jour, 1/jour la
  première semaine, 1/mois ensuite…), avec un tri assisté par Gemini.

Spécifications : [docs/SPECS.md](docs/SPECS.md).
